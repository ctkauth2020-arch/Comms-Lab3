# Comms-Lab3
Lab 3 repo for communications engineering

### Intro
This repository was formed to contain the deliverables for third lab of EEGR4614 Communications Engineering taught by Professor Allen Morrison.

The purpose of this lab is to demonstrate principles of carrier modulated digital communications by finding the operating frequency of a garage opener unit and demodulate the signal to obtain a binary sequence using a HackRF SDR and GNU Radio Companion software.

Found on the main page of the repo are screenshots of the various output graphs and sinks as well as the GNU Radio Companion block diagrams and this README.

I have gained a much better understanding of python coding, radio functionality, core electrical engineering principles such as frequency and spectra behavior, and common trouble-shooting processes found when dealing with virtual and real radio equipment as well as with computer terminals and command prompts.
